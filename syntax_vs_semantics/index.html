Mengenal Syntax dan Semantics dalam Bahasa Pemrograman

Dalam pemrograman komputer, kita tidak bisa langsung menyuruh komputer untuk melakukan sesuatu dengan bahasa manusia; kita harus menulis baris kode yang akan di-compile sehingga komputer dapat mengerti apa instruksi kita. Dengan ini, fungsi bahasa pemrograman adalah jembatan bagi manusia dan komputer. Sama seperti bahasa manusia, bahasa pemrograman juga memiliki struktur yang terdiri dari syntax dan semantics. Di blog ini, saya akan menjelaskan apa itu syntax dan semantics dalam bahasa pemrograman.

Apa itu syntax?

Syntax merupakan struktur dari bahasa-bahasa. Secara jelas, syntax merupakan aturan penempatan struktur kalimat yang ada di bahasa-bahasa; tidak hanya bahasa manusia yang memiliki syntax, namun bahasa pemrograman juga memiliki syntax. Diberikan suatu contoh: “Saya sedang meminum susu,” merupakan suatu kalimat yang memiliki syntax yang benar di bahasa Indonesia atau Melayu; penulisan syntax juga dapat salah apabila kita menulisnya dengan kalimat: “Sedang meminum saya susu,” karena tidak sesuai dengan kaidah bahasa tersebut. Sama seperti di bahasa pemrograman, syntax juga tergantung dengan bahasa pemrograman yang digunakan; untuk sebagai contoh di bahasa pemrograman C:

#include <stdio.h>

int main(){
    int a=10;
    printf("%d\n",a);
    return 0;
}

Kode di atas dapat dikatakan benar, karena kode yang ditulis sudah sesuai dengan kaidah bahasa pemrograman C. Diberikan pula contoh yang salah di bahasa pemrograman C:

#include <stdio.h>

int main(){
    a int = 10;
    printf("%d\n",a);
    return 0;
}

Kode tersebut salah karena tidak memenuhi kaidah syntax bahasa pemrograman C yang di mana penulisan deklarasi variabel harus “int (nama variabel) = (isi variabel).” Sehingga kode tidak akan di-compile oleh C compiler karena di bagian tahap pengecekan syntax gagal dan tidak dapat melakukan tahap berikutnya, yaitu: analisis semantics.

Apa itu semantics?

Semantics merupakan makna dari suatu kalimat, jika syntax sudah sesuai kaidah bahasa tersebut maka kita dapat mengetahui apa makna dari kalimat tersebut. Bagaimana kita mengetahui bagaimana semantics dari suatu kalimat sudah benar dengan kita melakukan analisis logika, “apakah kalimat tersebut masuk akal?” Sebagai contoh di dalam kalimat bahasa Indonesia atau Melayu: “Saya sedang minum sepiring nasi,” kalimat tersebut sudah benar secara syntax dari bahasa tersebut, namun hal yang masih kurang benar adalah makna dari kalimat tersebut. Diberikan suatu kode di bahasa pemrograman C:

#include <stdio.h>

int main(){
    int a=10;
    printf("%d\n",a);
    return 0;
}

Kode di atas sudah benar secara semantics karena sudah memenuhi logika “apakah kode tersebut masuk akal.” Jika kita analisis kode tersebut, kita sudah mendeklarasikan variabel; manuliskan output dengan fungsi printf yang sudah memenuhi parameter yang diperlukan; sudah melakukan return bilangan di fungsi integer. Sehingga kode ini dapat berlanjut ke langkah selanjutnya untuk melakukan kompilasi. Untuk kode yang tidak benar, diberikan kode C di bawah ini:

#include <stdio.h>

int main(){
    a = 10;
    printf("%d\n",a);
    return 0;
}

Kode di atas, secara penulisan sudah benar. Dengan assign variabel, pemanggilan fungsi printf, return secara benar sesuai kaidah syntax bahasa pemrograman C. Namun jika kita perhatikan, terdapat kode a=10 tanpa deklarasi variabel, meskipun secara syntax sudah benar tetapi kode tersebut tidaklah logis; jika kita ingin melakukan assign variabel kita harus mendeklarasikan variabel terlebih dahulu di bahasa pemrograman C.

Kesimpulan

Syntax dan semantics merupakan dua konsep dasar yang harus dipahami ketika mempelajari bahasa pemrograman. Syntax berfokus pada aturan penulisan kode agar sesuai dengan tata bahasa suatu bahasa pemrograman, sedangkan semantics berfokus pada makna atau logika dari kode yang ditulis. Sebuah program dengan syntax yang salah tidak dapat diproses lebih lanjut oleh compiler karena tidak memenuhi aturan penulisan. Sebaliknya, program yang memiliki syntax benar belum tentu benar secara semantics; compiler masih harus memastikan bahwa kode tersebut memenuhi aturan seperti deklarasi variabel, kesesuaian tipe data, ruang lingkup (scope), serta penggunaan fungsi yang benar.

Dengan memahami perbedaan antara syntax dan semantics, seorang programmer dapat lebih mudah mengidentifikasi sumber kesalahan yang muncul saat proses kompilasi. Hal ini juga membantu dalam menulis kode yang tidak hanya valid menurut aturan bahasa, tetapi juga memiliki makna yang benar sehingga dapat dijalankan sesuai dengan tujuan program.
